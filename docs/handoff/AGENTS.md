# AI 交接约定

先读 STATUS.md、../architecture.md 和根 README，再检查 Git 状态。所有 AI 交接文档放在 docs/handoff，根目录不放 AGENTS.md。

- 保留独立的前后端源码仓库，本仓库仅负责统一配置与部署。
- 统一配置默认根 config.yaml。每个应用进程必须显式指定自己的 CONFIG_FILE；不得让父进程的统一配置路径泄漏给子进程。
- 保留已配置的应用主密钥、TOTP 主密钥和节点凭据；自动生成只用于新站点。私有配置、环境、数据和缓存不能提交。
- 浏览器配置修改要做三方合并；同字段冲突报错，不静默覆盖。
- 自动更新使用 git pull --ff-only。用户已明确确认是 pull，不是 push。禁止自动 reset、stash、强推或覆盖脏工作树。
- 构建失败保留当前运行版本；更新后的代码快照与依赖一起交付。前端重启不编译。
- 业务启动不做 DDL；部署准备只可初始化确认空的库，已有数据库迁移显式执行。
- 内部接口保持真实 socket 来源与 Token 双重检查；复用后端已有节点服务，勿直接操作注册表绕过锁与审计。
- 测试不得访问用户生产数据库或 Redis。运行改动需要真实多进程验收；Docker 无可用 daemon 时如实记录，不能把命令测试称为镜像实测。
- 使用完整的本地提交，更新 STATUS.md。沿用项目交接约定，远程推送由用户执行，除非本次交付有明确的新授权。
